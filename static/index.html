Последние военные операции

Информационная панель:

• Все операции автоматически сохраняются

• Учитываются: пользователь, планета, тип операции, результат

• Красные кружки - окруженные планеты

• Золотые планеты - с доступными миссиями

• Синие линии - связи между планетами одной фракции

Основная команда:

alphaStrike.completeMission('Brighton', 0, [
  {id: 1, faction: 'stives'},
  {id: 2, faction: 'capellan'}
], 150, 'stives', 'Описание миссии')

Параметры:

• participants: массив объектов {id, faction}

• points: очки перевеса (от 0 до 500)

• winningFaction: 'stives' или 'capellan'

• description: текстовое описание
